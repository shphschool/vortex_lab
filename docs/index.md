# Vortex Lab

Welcome to the **Vortex Lab** documentation! This site is built with [Jekyll](https://jekyllrb.com/) using the [Just the Docs](https://just-the-docs.github.io/just-the-docs/) theme and deployed via [GitHub Pages](https://pages.github.com/).

{: .note }
> This documentation site is maintained in the `docs/` directory of the `vortex_lab` repository.

## Features

- **Full-text search**: Fast, client-side indexing and searching across all documentation pages.
- **Responsive design**: Clean layout optimized for desktop, tablet, and mobile viewing.
- **Code highlighting & callouts**: Native syntax highlighting with customizable callout boxes for tips, notes, and warnings.
- **Automated CI/CD**: Seamless builds and deployments on every push to `main` via GitHub Actions.
